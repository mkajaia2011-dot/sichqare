1. Antigravity-ს ჩამოტვირთვა და საქაღალდის მომზადება

Antigravity (ან VS Code / IDE) არის კოდის მართვისა და რედაქტირების თანამედროვე გარემო. სანამ კოდის წერას დავიწყებთ, მოვაწესრიგოთ სამუშაო სივრცე.

ნაბიჯ-ნაბიჯ ინსტრუქცია:

  1. Antigravity / VS Code-ის გადმოწერა: გადადით ოფიციალურ საიტზე და გადმოწერეთ ინსტალატორი Windows ან Mac-ისთვის.
  2. ინსტალაცია: გაშვით გადმოწერილი ფაილი და მიჰყევით სტანდარტულ ნაბიჯებს (Next -> Finish).
  3. სამუშაო საქაღალდის შექმნა:
    • სამუშაო მაგიდაზე (Desktop) დააჭირეთ მაუსის მარჯვენა ღილაკს.
    • აირჩიეთ New -> Folder (ახალი საქაღალდე).
    • დაარქვით სახელი: chemistry-app.
  4. საქაღალდის გახსნა პროგრამაში: გახსენით Antigravity, აირჩიეთ Menu -> File -> Open Folder და აირჩიეთ თქვენი შექმნილი chemistry-app საქაღალდე.
ყოველთვის შეინახეთ პროექტის ყველა ფაილი ერთ კონკრეტულ საქაღალდეში!

2. Gemini AI-სთვის დავალების მიცემა (Prompting)

ახლა გადავდივართ Gemini AI-ზე (gemini.google.com). ჩვენ მას ვთხოვთ, დაგვიწეროს სრული HTML, CSS და JavaScript კოდი ქიმიური რეაქციის სიჩქარის სიმულაციისთვის.

დააკოპირეთ ეს ბრძანება (Prompt) Gemini-სთვის:

Prompt Gemini AI-სთვის 
შემიქმენი ინტერაქციული ვებ-აპლიკაცია (HTML/CSS/JS ერთ ფაილში), სადაც ნაჩვენებია ქიმიური რეაქციის სიჩქარის დამოკიდებულება ტემპერატურაზე, კონცენტრაციასა და კატალიზატორზე. აპლიკაციას ჰქონდეს სლაიდერები ამ პარამეტრების შესაცვლელად და ვიზუალური ნაწილაკების ანიმაცია, რომელიც აჩვენებს რეაქციის სიჩქარეს.

რა პასუხს მოგვცემს Gemini:

Gemini დააგენერირებს კოდის ბლოკს, რომელსაც ზედა მარჯვენა კუთხეში ექნება ღილაკი "Copy code".

3. კოდის გადატანა Antigravity-ში და გაშვება

მიღებული კოდი უნდა ჩავსვათ Antigravity-ში შექმნილ ახალ ფაილში.

მოქმედებების თანმიმდევრობა:

  1. Antigravity-ში დააჭირეთ Ctrl + N (ახალი ფაილი).
  2. ჩასვით დაკოპირებული კოდი (Ctrl + V).
  3. დააჭირეთ Ctrl + S (შენახვა) და ფაილს დაარქვით index.html.
  4. გახსენით საქაღალდე chemistry-app და ორჯერ დააწკაპუნეთ index.html-ს. აპლიკაცია გაიხსნება ბრაუზერში!

შექმნილი აპლიკაციის ინტერაქციული სიმულაცია (Preview):

4. GitHub-ზე დარეგისტრირება

იმისათვის, რომ აპლიკაცია ინტერნეტში გახდეს ხელმისაწვდომი ყველასთვის, გამოვიყენებთ GitHub-ს.

რეგისტრაციის ნაბიჯები:

  1. გადადით საიტზე: github.com.
  2. დააჭირეთ ღილაკს "Sign up".
  3. შეიყვანეთ თქვენი ელ-ფოსტა, შექმენით პაროლი და მომხმარებლის სახელი (Username).
  4. გაიარეთ უსაფრთხოების მარტივი შემოწმება (Captcha) და დააჭირეთ Create account.
  5. შეამოწმეთ ელ-ფოსტა და ჩასვით დადასტურების კოდი.

5. ფაილების ატვირთვა და GitHub Pages-ის ჩართვა

ეს არის ფინალური ეტაპი! ატვირთეთ თქვენი `index.html` ფაილი და მიიღეთ ცოცხალი ბმული.

ნაბიჯები საიტის გასაშვებად:

  1. GitHub-ზე ავტორიზაციის შემდეგ დააჭირეთ "+" ნიშანს (ზედა მარჯვენა კუთხეში) -> New repository.
  2. Repository name: ჩაწერთ მაგალითად: chemistry-speed-app.
  3. მონიშნეთ Public და დააჭირეთ Create repository.
  4. გახსნილ გვერდზე იპოვეთ ბმული: "uploading an existing file".
  5. გადმოათრიეთ თქვენი index.html ფაილი კომპიუტერიდან და დააჭირეთ Commit changes.
  6. GitHub Pages-ის ჩართვა:
    • გადადით რეპოზიტორიის ჩანართში Settings -> Pages (მარცხენა მენიუში).
    • Branch სექციაში None-ის ნაცვლად აირჩიეთ main (ან master) და დააჭირეთ Save.
  7. დაელოდეთ 1-2 წუთი! გვერდის დარეფრეშების შემდეგ გამოჩნდება მწვანე შეტყობინება თქვენი საიტის ბმულით! (მაგ: https://username.github.io/chemistry-speed-app/).
გილოცავთ! თქვენი აპლიკაცია უკვე ხელმისაწვდომია მთელ მსოფლიოში!
